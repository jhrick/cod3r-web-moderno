# Web Moderno — Registro de Aprendizagem

> Repositório de estudos e acompanhamento do curso **Web Moderno Completo com JavaScript + Projetos**, da [Cod3r](https://www.udemy.com/course/curso-web/).

## Sobre este repositório

Este repositório reúne os códigos, exercícios, desafios, projetos e anotações produzidos ao longo do curso. Seu objetivo é **registrar a evolução dos estudos**, preservando tanto as soluções desenvolvidas quanto os conceitos e decisões que surgirem durante o aprendizado.

O conteúdo está em desenvolvimento contínuo: diferentes módulos podem conter exemplos introdutórios, implementações parciais, revisões e projetos mais completos. O repositório não deve ser interpretado como uma única aplicação pronta para produção.

## Conteúdo estudado

O curso aborda fundamentos e ferramentas de desenvolvimento web, incluindo:

- **Fundamentos:** lógica de programação, JavaScript, programação funcional e orientação a objetos.
- **Frontend:** HTML, CSS, DOM, React, Vue e Next.js.
- **Backend:** Node.js, Express e APIs HTTP.
- **Dados:** SQL, bancos relacionais e MongoDB.
- **Ferramentas:** Gulp, Webpack e outras tecnologias utilizadas nos exercícios e projetos.

> A presença de uma tecnologia nesta lista indica que ela faz parte do programa do curso, **não que seu estudo já tenha sido concluído**.

- **Não iniciado:** módulo ainda não estudado.

- **Concluído:** conteúdo previsto para o módulo percorrido, sujeito a revisões futuras.

## Organização e documentação

Os diretórios serão organizados conforme os conteúdos e projetos efetivamente desenvolvidos. Sempre que pertinente, os registros poderão incluir:

- Código-fonte e exercícios práticos.
- Explicações sobre conceitos estudados.
- Desafios, soluções alternativas e experimentos.
- Observações sobre dificuldades, correções e aprendizados.
- Instruções de execução específicas de cada projeto.

A estrutura do repositório poderá mudar conforme a evolução dos estudos.
